# iStore

Application Java de gestion d'inventaire multi-magasins avec interface graphique.

---

## Description

iStore permet à des entreprises de gérer leurs stocks. Elle propose un système d'authentification sécurisé, une gestion des rôles et une interface graphique complète.

---

## Fonctionnalités

- Authentification sécurisée (mot de passe hashé, emails whitelistés)
- Gestion des rôles : admin, employé, utilisateur
- CRUD complet des utilisateurs
- Gestion de plusieurs magasins
- Gestion des stocks : ajouter, modifier, supprimer des articles
- Affichage de tous les articles disponibles

---

## Technologies

- Langage : Java
- Interface : Java Swing
- Base de données : relationnelle
